PACKAGE OVERVIEW
================

solvency2rfr provides tidy access to the monthly risk-free interest rate (RFR)
term structures published by the European Insurance and Occupational Pensions
Authority (EIOPA). These curves are essential inputs for calculating Solvency II
technical provisions across the European Economic Area.

The package downloads data from EIOPA's official RSS feed (https://www.eiopa.europa.eu/feed/53/rss_en),
extracts ZIP-archived Excel files, and returns data as clean, normalized tibbles
suitable for further analysis.

KEY FEATURES
============

- rfr_index(): List all available publications with reference dates and URLs
- rfr_term_structures(): Download and parse term structures for specific dates
- Multiple curve types: spot_no_VA, spot_with_VA, and four stress scenarios
- Clean, reproducible R code with roxygen2 documentation
- 25 passing unit tests (testthat)
- Comprehensive vignette with examples
- GitHub Actions CI workflow (5 platform/R-version combinations)

DEPENDENCIES
============

All dependencies are on CRAN:
- httr2 (>= 1.0.0): Modern HTTP client for downloading EIOPA files
- readxl (>= 1.4.0): Parse Excel files from EIOPA ZIP archives
- tibble (>= 3.2.0): Tidy tibble data structure
- xml2 (>= 1.3.0): Parse EIOPA RSS feed

Suggests: knitr, rmarkdown, testthat, withr

No external system dependencies required (vignette pre-built in inst/doc/).
